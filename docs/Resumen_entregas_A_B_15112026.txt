ENTREGA A: CAMBIO DE PANTALLA DE OBJETIVOS
------------------------------------------
1. clearTargets() y removeTarget(id) quitan el objetivo resaltado y el formulario
   agarrado. Ya no hace falta llamar antes a clearSelectedTarget().

2. Historia con hora. API nueva (la firma de siempre no cambia):
       qint64 addTarget(const MapTarget &target, const QVector<TargetTrackPoint> &history);
       bool   setTargetHistory(qint64 id, const QVector<TargetTrackPoint> &history);
   Los puntos entran tal cual (sin la distancia mínima de 1 m), en orden de tiempo.
   updateTarget sigue igual.

3. Carga silenciosa:
       void beginTargetLoad();
       void endTargetLoad();
   Entre las dos no se emiten alertas de zona ni de proximidad, pero el estado
   interno sí se actualiza.

4. Sectores y círculos con dueño:
       void clearTargets(bool keepOwnedFeatures = false);
   Con true quedan suspendidos (no se ven ni se pinchan) y reaparecen cuando
   vuelve un objetivo con el mismo id. Los anillos y marcaciones se conservan solos.

Secuencia para cambiar de pantalla:

    // guardar lo de la pantalla que se va
    for (const MapTarget &t : mapa->targets())
        guardado[t.id] = { t, mapa->targetHistory(t.id) };

    // cargar la nueva
    mapa->beginTargetLoad();
    mapa->clearTargets(true);
    for (const auto &g : pantallaNueva)
        mapa->addTarget(g.objetivo, g.historia);
    mapa->endTargetLoad();


ENTREGA B
---------
5. Todas las entidades bajo el cursor. La señal no cambia de firma y se emite una
   sola vez por clic; MapHit lleva la lista:
       struct MapHitFeature { qint64 id; int subIndex; };
       QVector<MapHitFeature> features;      // de arriba abajo; la primera es featureId
   Sin clic: QVector<MapHitFeature> MapWidget::featuresAt(pixel, tolerancePx = 8).

6. Seleccionar sin resaltar:
       f.highlightWhenSelected = false;      // por defecto, true
   El clic izquierdo la sigue seleccionando y emite featureSelected, pero no se
   dibuja el halo ni los tiradores. No toca selectable.

7. Caja de los rótulos. Por entidad, en FeatureStyle:
       QColor labelBackground = QColor(255, 255, 255, 190);   // alfa 0 = sin fondo
       QColor labelBorderColor;   double labelBorderWidth = 1.0;   // inválido = sin borde
       QColor labelHaloColor;     double labelHaloWidth = 2.0;     // inválido = sin halo
   Para anillos, marcaciones, cuadrícula y alertas de proximidad:
       LabelBoxStyle s;  s.background = ...;  mapa->setLabelBoxStyle(s);


A TENER EN CUENTA
-----------------
- highlightWhenSelected y los campos nuevos del rótulo NO se guardan en la BD de
  entidades: la app los pone al crear o cargar la entidad.
- Siguen con su caja fija: rótulos de inicio/fin de ruta, la medida en vivo, el
  origen del historial y la escala gráfica.
- Una entidad sin resaltado tampoco muestra tiradores al editarla: ponerle el
  resaltado mientras se edita a mano.
- Si la historia sembrada supera el tope (5000 puntos por defecto) se aclara una
  vez. Para conservarla entera, subir antes setTargetHistoryLimit.
- Las alertas de una pantalla oculta no saltan: sus objetivos no están en la librería.
- Los ids de objetivo deben ser únicos entre pantallas.

Una ventana con el mapa y un panel para tocar todo lo de las dos entregas, sin
usar la app real. Qué probar, paso a paso: examples/cambio_pantalla/README.md

Se compila contra la librería INSTALADA, como los demás ejemplos:

       cmake --install . --prefix C:/libmapa
  2. Compilar los ejemplos:
       cmake -S examples -B build-examples -DCMAKE_PREFIX_PATH="C:/libmapa;C:/Qt/6.11.2/mingw_64"
       cmake --build build-examples
     (o abrir examples/cambio_pantalla/cambio_pantalla.pro en Qt Creator)
  3. Lanzarlo con vuestro paquete de datos:
       cambio_pantalla.exe <carpeta del paquete de datos>
     Sin ventana, solo para comprobar (sale con 0 si todo está bien):
       cambio_pantalla.exe <carpeta del paquete de datos> --comprobar
